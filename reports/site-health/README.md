# Site health reports

Dated reports from the weekly automated health check
(`.github/workflows/weekly-site-health.yml`) are written here, one folder per
run date: `reports/site-health/YYYY-MM-DD/report.md` (plus a `raw-results.json`
with the underlying data).

Each report is read-only — generated by crawling the live production site and
running an accessibility scan against it. It never contains secrets or private
user data, and the workflow that produces it never modifies application code
or the live site on its own; every report lands in a draft pull request for
manual review.

To generate one manually:

```bash
SITE_URL=https://www.seanaustinmusic.com node scripts/weekly-site-health.mjs
```
